# Knowledge Base for RAG

هذا المجلد مخصص لقاعدة المعرفة التي سيستخدمها نظام RAG (Retrieval-Augmented Generation) في الإصدارات القادمة.

## البنية المقترحة

```
knowledge/
├── parenting/        # نصائح التربية
├── nutrition/        # التغذية الصحية
├── mental_health/    # الصحة النفسية
├── development/      # مراحل النمو
└── safety/          # السلامة والإسعافات الأولية
```

## التنسيق

الملفات يجب أن تكون بصيغة Markdown أو JSON، وتحتوي على:
- العنوان
- المحتوى
- التاجات (Tags)
- المصدر

## مثال

```json
{
  "title": "روتين النوم للأطفال",
  "content": "النوم المنتظم مهم جداً لنمو الطفل...",
  "tags": ["نوم", "روتين", "أطفال"],
  "source": "منظمة الصحة العالمية",
  "language": "ar"
}
```
