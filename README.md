## ✨ المميزات

### 🌟 المسارات الأساسية

#### 👶 يوميات الطفل
- **روتين النوم**: تذكيرات النوم، نصائح التهدئة، تتبع جودة النوم
- **التغذية**: اقتراحات وجبات صحية، إدخال أطعمة جديدة، تحذيرات الحساسية
- **اللعب والنشاط**: أفكار ألعاب هادفة (5-10 دقائق)
- **تطوير اللغة**: أسئلة، قصص قصيرة، ألعاب لفظية

#### 💙 صحة ونفسية الأسرة
- **دعم نفسي للوالدين**: تمارين تنفس، إعادة صياغة إيجابية
- **تواصل زوجي**: سؤال اليوم، تذكير بموعد أسبوعي
- **مسار التعلم**: كتب وكورسات مقترحة كل 3 أيام

#### 🎬 نهاية الأسبوع
- **ترشيحات أفلام**: فيلمين مناسبين مع سبب الاختيار
- **اقتراحات خروجات**: حسب الميزانية والمدة
- **Checklist التجهيز**: قائمة جاهزة للخروجة
- **بديل منزلي**: أنشطة ممتعة في المنزل

#### 📊 التقارير
- **تقرير أسبوعي**: إنجازات، إحصائيات، نقاط للتحسين، هدف الأسبوع القادم
- **تتبع خفيف**: أزرار سريعة للنوم/الأكل/المزاج

### 🤖 الذكاء الاصطناعي

- **رسائل مخصصة**: كل رسالة مولّدة خصيصاً لعائلتك
- **تحسين التوقيت**: يتعلم أفضل وقت لإرسال الرسائل
- **تعلم التفضيلات**: يتكيف مع اهتماماتك
- **حارس السلامة**: يمنع النصائح الطبية الخطرة

### ⚙️ التحكم الكامل

- **ملف YAML واحد**: جميع الإعدادات في مكان واحد
- **Hot Reload**: التغييرات تطبّق فوراً بدون إعادة تشغيل
- **لا كود**: كل شيء قابل للتخصيص من الإعدادات

## ⚙️ الإعداد

### 1. إعداد المتغيرات البيئية

انسخ ملف `.env.example` إلى `.env`:

```bash
cp .env.example .env
```

افتح ملف `.env` وأضف مفتاح OpenAI الخاص بك:

```env
# OpenAI API Configuration
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Database Configuration
DATABASE_PATH=./data/family_assistant.db

# Encryption Key (generate a random 32-character string)
ENCRYPTION_KEY=your_32_character_encryption_key_here

# Configuration File Path
CONFIG_PATH=./config/config.yaml

# Environment
NODE_ENV=production
```

### 2. توليد مفتاح التشفير

لتوليد مفتاح تشفير آمن (32 حرف):

```bash
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

انسخ الناتج وضعه في `ENCRYPTION_KEY` في ملف `.env`.

### 3. تخصيص الإعدادات

افتح ملف `config/config.yaml` وعدّل الإعدادات حسب احتياجاتك:

```yaml
app:
  timezone: "Africa/Cairo"  # المنطقة الزمنية
  language_default: "ar"    # اللغة الافتراضية
  quiet_hours:
    start: "22:00"          # بداية ساعات الهدوء
    end: "06:30"            # نهاية ساعات الهدوء

ai:
  llm:
    model: "gpt-5"          # نموذج الذكاء الاصطناعي
    temperature: 0.6        # درجة الإبداع (0-1)

weekend:
  send:
    day: "Thu"              # يوم إرسال خطة نهاية الأسبوع
    time: "18:30"           # وقت الإرسال
```

## 📱 الاستخدام

### الإعداد الأولي (Onboarding)

عند التحدث للبوت لأول مرة، سيسألك:

1. **اسمك**
2. **دورك** (الأب/الأم)
3. **اسم العائلة**
4. **المنطقة الزمنية**
5. **الوقت المفضل** للرسائل
6. **عدد الأطفال**
7. **معلومات كل طفل** (الاسم، تاريخ الميلاد، الحساسيات)
8. **المسارات المفضلة**

### الرسائل اليومية

بعد الإعداد، ستبدأ باستقبال:

- **صباحاً (7:30)**: نصائح النوم والإفطار
- **ظهراً (13:30)**: أنشطة اللعب واللغة
- **مساءً (19:00)**: روتين التهدئة وقصة قبل النوم

### التفاعل مع الرسائل

كل رسالة تأتي مع أزرار:

1. **تم ✅**: تأكيد إتمام المهمة
2. **ذكّرني لاحقاً ⏰**: تأجيل ساعة
3. **بدّل التوقيت 🔄**: تغيير وقت الرسائل
4. **تخطي ⏭️**: تخطي هذه الرسالة

ببساطة، اكتب رقم الزر أو النص (مثل "تم" أو "1").

### خطة نهاية الأسبوع

كل **خميس 6:30 م**، ستحصل على:

- فيلمين مقترحين
- فكرة خروجة عائلية
- قائمة تحضيرات
- بديل منزلي

### التقرير الأسبوعي

كل **جمعة 9:00 ص**، ستحصل على تقرير يشمل:

- إنجازات الأسبوع
- إحصائيات (نوم، تغذية، لعب)
- نقاط للتحسين
- هدف الأسبوع القادم

## 🎨 التخصيص

### تغيير المسارات

في `config/config.yaml`:

```yaml
tracks:
  daily:
    - child_sleep
    - child_nutrition
    - child_play
    - child_language
    - parents_mental
    - parents_learning

  optional:
    - family_values
    - prayer_times        # أوقات الصلاة (اختياري)
    - weekend_planner
```

### تغيير كثافة الرسائل

```yaml
tracks:
  density:
    morning: 1    # عدد الرسائل صباحاً
    noon: 1       # عدد الرسائل ظهراً
    evening: 1    # عدد الرسائل مساءً
```

### تخصيص الأزرار

```yaml
ui:
  buttons:
    - "تم ✅"
    - "ذكّرني لاحقاً ⏰"
    - "بدّل التوقيت 🔄"
    - "تخطي ⏭️"
```

### تفعيل/تعطيل ميزات

```yaml
weekend:
  enabled: true          # تفعيل خطة نهاية الأسبوع
  movies:
    enabled: true        # تفعيل ترشيحات الأفلام
  outings:
    enabled: true        # تفعيل اقتراحات الخروجات

reminders:
  vaccines: true         # تفعيل تذكيرات التطعيمات
  prayer_times:
    enabled: true        # تفعيل أوقات الصلاة
    city: "Cairo"
```

## 🔒 الأمان والخصوصية

### التشفير

- جميع البيانات الحساسة (أرقام الهواتف، معلومات الحساسيات) **مشفرة** في قاعدة البيانات
- التشفير يستخدم مفتاح `ENCRYPTION_KEY` من ملف `.env`

### التخزين المحلي

- **جميع البيانات محفوظة محلياً** على جهازك
- **لا توجد خوادم خارجية** لتخزين البيانات
- **لا مشاركة بيانات** مع أطراف ثالثة

### OpenAI API

- الرسائل المولّدة تُرسل لـ OpenAI فقط لتوليد النص
- لا تُخزَّن محادثاتك عند OpenAI (Zero Data Retention)
- يمكنك استخدام نماذج محلية بدلاً من OpenAI

### مدة الاحتفاظ

- الافتراضي: **365 يوم**
- قابل للتعديل في `config/config.yaml`:

```yaml
privacy:
  data_retention_days: 365
```

### حذف البيانات

أرسل للبوت: `انساني`

سيطلب منك التأكيد، ثم يحذف:
- جميع بيانات العائلة
- معلومات الأطفال
- التفاعلات والإحصائيات
- الرسائل المجدولة

## 🐛 استكشاف الأخطاء

### المشكلة: لا يظهر رمز QR

**الحل:**
- تأكد من تثبيت جميع المكتبات: `npm install`
- جرب حذف مجلد `.wwebjs_auth/` وأعد التشغيل

### المشكلة: "OpenAI API Key not found"

**الحل:**
- تأكد من وجود ملف `.env`
- تأكد من صحة `OPENAI_API_KEY` في `.env`
- أعد تشغيل التطبيق

### المشكلة: البوت لا يرد على الرسائل

**الحل:**
- تأكد من إكمال عملية Onboarding
- تحقق من السجلات (Logs) لرؤية الأخطاء
- أرسل "مساعدة" للتأكد من أن البوت يعمل

### المشكلة: الرسائل اليومية لا تُرسل

**الحل:**
- تأكد من تشغيل المجدول (Scheduler)
- تحقق من `config/config.yaml` أن المسارات مفعّلة
- تحقق من أوقات الجدولة في السجلات

### المشكلة: Hot Reload لا يعمل

**الحل:**
- تأكد من `hot_reload: true` في `config/config.yaml`
- أعد تشغيل التطبيق
