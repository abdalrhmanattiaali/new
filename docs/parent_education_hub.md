# مركز التعلم التفاعلي للوالدين

هذا المستند يوضح كيف يعمل مسار "التعليم الذكي" للوالدين، والذي يجمع الكتب، الكورسات، فيديوهات الخبراء (YouTube/Facebook)، مقاطع أطباء الأطفال، وتمارين ذهنية/عقلية في حزمة واحدة يومية يديرها الذكاء الاصطناعي.

## المبادئ
- إشعار واحد في الساعة كحد أقصى (يتكامل مع المنسق الموحد).
- استخدام نطاقات موثوقة فقط للروابط (YouTube, Facebook, WHO, UNICEF).
- تجنّب التكرار عبر تمرير سجل الموارد الأخيرة للـAI.
- لغة عربية مهنية دافئة مع تذكير بعمر الطفل بالأيام.
- مراعاة حالة الأب (في المنزل/خارج المنزل) ونبرة تقدير مجهود الوالدين.

## جدولة افتراضية
- **وقت الفحص اليومي:** `20:30` (قابلة للتعديل في `config.yaml` تحت `parent_resources.education_hub`).
- **الفاصل الزمني:** 4-6 أيام بين الحزم (يُحسب لكل عائلة حسب آخر إرسال).

## مكونات الحزمة
1. مقطع موثوق لطبيب أطفال أو خبير تنمية (رابط مباشر مسموح).
2. ترشيح كتاب عملي + خطوة تطبيق خلال 48 ساعة.
3. كورس مصغر (≤60 دقيقة) أو تمرين ذهني/عقلي للأبوين.
4. فيديو استرخاء/تنفس سريع للأب أو الأم حسب حالتهم.

## مثال سجل سياق يُرسل للـAI
```jsonl
{"role":"system","content":"...system prompt..."}
{"role":"user","content":"آخر الموارد المرسلة:\n- video: فيديو يوغا تنفس (2024-06-01)\n- course_mother: كورس توازن الأم العاملة (2024-06-05)\n- book: الأبوان الواعيان (2024-06-12)\nالنطاقات المسموحة: youtube.com, facebook.com, who.int"}
```

## نصيحة تشغيلية
- حدّث الحقول `categories`, `fallback_links`, و`allowed_domains` بحسب سياسات الموثوقية لديك.
- راقب سجل `parent_resource_logs` للتأكد من التنوع، واضبط `min_gap_days` / `max_gap_days` حسب تفاعل العائلة.
- عند إضافة موارد يدوية، التزم بنفس النطاقات المسموحة حتى لا تُرفض الروابط عند الإرسال.
