# Prompt لبناء مساعد العائلة الذكي من الصفر

استخدم النص التالي كبرومبت شامل إذا احتجت لإعادة بناء المشروع من جديد (تطوير بوت واتساب عائلي ذكي بالذكاء الاصطناعي):

```
أنت GPT-5.1-Codex-Max. طوّر نظام "مساعد عائلة واتساب" باللغة العربية يدعم الآتي:

المعمارية الأساسية
- Node.js 18+ مع ESM.
- بوت واتساب عبر whatsapp-web.js (جلسة LocalAuth)، مع حظر إرسال أي رسالة إلا لجروبات/أفراد مصرح بهم في ملف allowed_groups.json.
- قاعدة بيانات Better SQLite مع مخطط للجروبات، العائلات، الأوصياء، الأطفال، السجلات التفاعلية، الموارد، التاريخ الإشعاري، وحسابات الذكاء الاصطناعي.
- خدمة LLM مهيّأة بـ OpenAI (Responses/Chat Completions) مع تمكين RAG من KnowledgeBase.

الميزات الرئيسة
- جدولة إشعار واحد في الساعة عبر orchestrator موحّد يعتمد notification_manifest.json، مع سجل notification_history لكل رسالة.
- ذاكرة تفاعلية: interactiveDialogueService تحفظ جلسات الأسئلة/الشكاوى وتحقن التاريخ في الـLLM.
- مسارات المحتوى: رسائل يومية، روتين روحاني، قصص صوتية (ElevenLabs)، تخطيط نهاية الأسبوع، تقارير أسبوعية/شهرية للمعالم، مسائل الطفل، مشاكل زوجية، مركز تعلّم الوالدين (كتب/دورات/فيديوهات)، أسئلة استنباطية، تنبيهات طقس.
- تنويع النص حسب عمر الطفل بالأيام، تسلسل الإشعارات، الحالة النشطة (مشاكل طفل، حضور الأب، معنويات الزوجين)، وروابط موارد متحقَّقة من نطاقات موثوقة.
- أزرار تفاعلية نصية فقط (لا قوائم)، مع مسارات fallback عند رفض أزرار من واتساب.

الخدمات والجدولة
- Scheduler يشغل: daily messages، spiritualRoutine، weather صباح/مساء، weekend planner previews، parent resources (كتب/كورسات/فيديوهات)، audio stories 10م، milestones أسبوعية/شهرية، inference questions، interactive notifications (AI+)، presence check للأب.
- pending sender يمنع رسائل متتابعة لنفس الوجهة في الدورة نفسها.

التكوين والملفات
- config/config.yaml يحوي مفاتيح OpenAI، ElevenLabs، إعدادات الطقس، الجدولة، toggles لكل خدمة.
- config/notification_manifest.json يعرّف أنواع الرسائل المسموح بها.
- README/SETUP_GROUP يشرح الإعداد، التشغيل، وتسجيل الجروبات المصرح بها.

المتطلبات التشغيلية
- توفير أوامر npm scripts للتشغيل المحلي و pm2.
- تغطية اختبارات/تشغيل يدوي أساسي.
- التزام بلغة عربية احترافية حنونة مع احترام السلامة النفسية والدينية.

المخرجات
- كود كامل، مخططات DB (schema.js + init migration)، خدمات في src/services، معالجات الرسائل في src/handlers/messageHandler.js، بوت واتساب في src/bot/whatsapp.js، ووثائق في مجلد docs (جداول الإشعارات، قوالب السياق التفاعلي، إلخ).
```

> يمكن تعديل البرومبت لتحديث أي تفاصيل (مثل النموذج أو الروابط الاحتياطية)، لكن حافظ على حدود "إشعار واحد في الساعة" وتاريخ الإشعارات لتعزيز الذكاء التفاعلي.
