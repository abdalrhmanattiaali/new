# لوحة التحكم العصرية

لوحة تحكم ويب خفيفة يمكن الوصول إليها عبر المتصفح لإدارة الإشعارات الموحدة، إطلاق اختبارات سريعة، وطلب اقتراحات تكوين من الذكاء الاصطناعي بنبرة احترافية حنونة.

## كيفية التشغيل
- تأكد من أن `dashboard.enabled` مفعّلة في `config/config.yaml` مع المنفذ المطلوب (الافتراضي 8090).
- شغّل التطبيق كالمعتاد (`npm start` أو عبر PM2). سيظهر سجل `🖥️  Dashboard available on port ...` عند التشغيل.
- افتح المتصفح على `http://<SERVER_IP>:<PORT>/` لمشاهدة اللوحة.

## مكونات اللوحة
- **البطاقات الرئيسية:** تعرض عدد الأسر، الأوصياء، الأطفال، الرسائل المعلقة، والجروبات المسموح بها (مأخوذة من قاعدة البيانات وملف `config/allowed_groups.json`).
- **أزرار الاختبار:** لكل ميزة معرفة في `dashboard.features` زر يطلق رسالة تجريبية عبر الـ Orchestrator مع احترام حد «إشعار واحد في الساعة». يمكن تمرير معرّف الأسرة والوصي يدويًا.
- **اقتراحات AI:** نموذج إدخال يرسل الموضوع والسياق إلى مسار `/api/dashboard/ai-suggest` لتوليد تكوين أو قالب مدعوم بالهيستوري.
- **سجل حديث:** عرض لأحدث الإشعارات المجدولة/المرسلة للأسرة الافتراضية لتقييم التنوع والنبرة.

## إعداد المزايا والألوان
- حدّث قسم `dashboard.features` لإضافة/إزالة أزرار الاختبار أو تغيير `message_type` التي تُستخدم في الاختبار.
- استخدم `dashboard.ai_hint` لتوجيه نبرة الاقتراحات أو نوع المخرجات المطلوبة (YAML/JSONL/نص).
- تدعم الواجهة ألوانًا متدرجة حديثة وخط Cairo/Inter المدمج عبر CSS الداخلي، ولا تحتاج إلى أي ملفات ثابتة إضافية.

## مسارات الـ API المتاحة
- `GET /api/dashboard/summary` إرجاع الملخص والعدادات.
- `GET /api/dashboard/history?family_id=ID&limit=N` لعرض آخر N إشعارًا لأسرة محددة.
- `POST /api/dashboard/test` ببيانات `{ featureId, familyId?, guardianId? }` لجدولة رسالة اختبار.
- `POST /api/dashboard/ai-suggest` ببيانات `{ topic, context, desiredFormat }` لطلب اقتراح من الذكاء الاصطناعي.

> ملاحظة: تتم جدولة الرسائل الاختبارية باستخدام `NotificationOrchestrator` وتُسجل في `notification_history` لضمان أن الذكاء الاصطناعي مطلع على التاريخ قبل توليد رسائل لاحقة.
